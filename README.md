# OrderFlow — Microservices Patterns Lab (Python)

A hands-on project for learning 57 microservice design patterns by evolving **one** order-processing
system from a modular monolith into a fully distributed, observable, Kubernetes-deployed platform.
Every pattern ends as working code, with tests and a runnable demo that shows the failure without it and the fix with it.

| Start here | Purpose |
|---|---|
| `SETUP.md` | Set up VS Code, tools, and Claude Code from scratch |
| `CLAUDE.md` | Instructions Claude Code reads automatically every session |
| `docs/PROJECT_BRIEF.md` | What we are building: domain, services, events, constraints |
| `docs/ROADMAP.md` | Phases 0–9: tasks, break-it experiments, acceptance criteria |
| `docs/PATTERN_CATALOG.md` | Every pattern → phase → trade-off → your code location |
| `docs/SESSION_PLAYBOOK.md` | Copy-paste prompts and habits for working with Claude Code |
| `docs/PROGRESS.md` | Current phase and session log (loaded into every Claude session) |
| `docs/adr/` | One Architecture Decision Record per pattern |

**The loop for every phase:** Understand → Break it → Fix with the pattern → Prove it (tests and demo) → Record the ADR → Tag it.

View these files on a laptop in VS Code: press `Ctrl+Shift+V` (`Cmd+Shift+V` on Mac) for the Markdown preview. Diagrams need the recommended Mermaid extension.
